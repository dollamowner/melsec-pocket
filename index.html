자료 범위 안내
현재 등록한 명령어는 업로드된 「PLC 공통명령편」의 MELSEC-Q/QnA 목차와 본문을 기준으로 정리했습니다. 이 파일은 iQ-R 전용 매뉴얼이 아니므로 R 시리즈에 동일하게 적용된다고 표시하지 않습니다. R 전용 매뉴얼을 추가하면 같은 검색 화면에 별도 데이터로 통합할 수 있습니다.
명령어 이름이나 설명을 검색하세요.
출처: 사용자가 제공한 「PLC공통명령편.pdf」. 목차 및 본문에 표시된 장·절·페이지를 기록했습니다.
주의: 명령어 요약은 빠른 검색용이며, 실제 설비 적용 전에는 해당 CPU 모델, 지원 디바이스, 명령 조건 및 원본 매뉴얼을 확인하세요. 현재 프로토타입은 HTML 파일 안에 검색 데이터를 포함해 검색 화면 자체는 네트워크 없이 동작합니다. 홈 화면 설치와 iOS 오프라인 캐시는 별도 배포 단계가 필요합니다.
