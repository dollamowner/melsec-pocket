# MELSEC Pocket — 보안 강화 PWA 패키지

## 포함 기능
- 홈 화면 설치용 웹앱 매니페스트와 아이콘
- 서비스 워커 오프라인 캐시
- CSS/JavaScript 외부 파일 분리
- 엄격한 Content Security Policy(CSP) 메타 정책
- 앱 검색은 로컬 데이터로 처리, 외부 API/분석/광고 SDK 없음
- 즐겨찾기만 localStorage에 저장

## 배포·설치
1. 정적 호스팅에 파일 전체를 업로드하고 HTTPS 주소를 생성합니다.
2. iPhone Safari에서 해당 HTTPS 주소를 엽니다.
3. 공유 → 홈 화면에 추가 → '웹 앱으로 열기' → 추가합니다.
4. 온라인 상태에서 최초 실행 후 비행기 모드에서 검색이 되는지 테스트합니다.

## 보안과 공개 범위
- GitHub Pages 무료 플랜은 public 저장소를 사용해야 하며, 게시된 사이트는 인터넷에 공개됩니다. 사이트 주소를 아는 사람만 볼 수 있는 비공개 앱이 아닙니다.
- 이 앱은 계정·비밀번호·설비 IP·래더 프로그램 등 민감정보를 받거나 저장하지 않도록 설계했습니다. 그런 자료를 추가하지 마세요.
- CSP는 외부 스크립트 실행 위험을 줄이는 보조 방어선입니다. 모든 해킹 위험을 없애지는 않습니다.
- 서비스 워커는 같은 출처의 GET 요청만 캐시하도록 제한합니다. 앱 데이터는 앱 파일에 포함되고 외부 API 호출을 하지 않습니다.
- HTTPS 호스팅 및 호스팅 계정에 강력하고 고유한 비밀번호와 2단계 인증을 사용하세요.
- 오프라인 캐시는 iOS가 공간 확보를 위해 삭제할 수 있어 영구 저장을 보장하지 않습니다.

## 기술 자료 주의
현재 Q/QnA 자료는 업로드된 매뉴얼 기반 프로토타입입니다. iQ-R 데이터는 아직 검증된 데이터베이스가 아닙니다. 실제 설비 적용 전에는 CPU 모델과 공식 원문을 확인하세요.
